# 软件说明书

## 一、软件概述

**软件全称**：智能场馆预约与优化管理系统  
**软件简称**：场馆预约系统  
**版本号**：V1.0  
**开发完成日期**：2026年8月  

**软件用途**：本软件是一款面向高校及社区体育场馆的智能化预约管理平台，通过模拟退火算法实现场地资源的全局最优分配，解决传统预约系统中存在的场地冲突、分配不均、用户偏好匹配度低等问题。

**开发环境**：
- 操作系统：Windows 10/11
- 开发语言：Python 3.10
- Web框架：Flask 2.3
- 数据库：SQLite 3
- 前端技术：HTML5 + CSS3 + JavaScript
- 算法库：NumPy

## 二、软件功能模块

本系统由三大核心模块组成：用户端、管理端、算法引擎。

### 2.1 用户端功能

| 功能模块 | 具体功能 |
|---------|---------|
| 用户管理 | 用户注册、登录、角色分配（普通用户/管理员） |
| 场地浏览 | 查看场地列表、类型、位置、实时状态 |
| 智能推荐 | 基于历史预约记录推荐偏好场地 |
| 在线预约 | 选择场地、日期、时段，提交预约 |
| 我的预约 | 查看预约记录、签到、取消预约 |

### 2.2 管理端功能

| 功能模块 | 具体功能 |
|---------|---------|
| 全局优化 | 执行模拟退火算法，计算最优场地分配方案 |
| 匹配率统计 | 查看理论匹配率与实际匹配率对比 |
| 用户管理 | 查看普通用户列表及偏好分析 |
| 超时释放 | 自动释放15分钟未签到的预约 |

### 2.3 算法引擎功能

| 功能模块 | 具体功能 |
|---------|---------|
| 模拟退火优化 | 带时间维度和场地唯一性约束的全局优化 |
| 适应度计算 | 综合类型匹配、时段匹配、楼层匹配的评分 |
| 约束检查 | 确保同一时段同一场地只分配给一个用户 |
| 多参数调优 | 支持温度、迭代次数、冷却系数等参数调整 |

## 三、软件使用说明

### 3.1 用户注册与登录

打开系统首页，新用户点击"注册"按钮，填写用户名、密码，可选择输入邀请码注册为管理员。注册成功后使用用户名和密码登录。

### 3.2 场地预约

登录后进入"场地看板"页面，系统会根据用户历史预约记录自动推荐场地。点击空闲场地，弹出预约窗口，选择日期和时间段，确认后完成预约。预约成功后场地状态变为"预约中"。

### 3.3 签到与取消

在"我的预约"页面，可对"预约中"的订单进行签到（状态变为"已使用"）或取消（状态变为"已取消"，释放场地）。系统会在预约后15分钟自动检查，未签到则自动释放场地。

### 3.4 全局优化（管理员）

管理员登录后进入"全局优化"页面，点击"执行全局优化"按钮，系统调用模拟退火算法，综合考虑所有用户的场地偏好、时段偏好，计算最优分配方案。优化结果以卡片形式展示，显示每个用户分配的场地及匹配度。

## 四、软件技术特点

1. **智能推荐算法**：基于用户历史预约数据，采用类型匹配（50%）、楼层匹配（30%）、时段匹配（20%）的加权评分机制，精准推荐偏好场地。

2. **模拟退火全局优化**：引入模拟退火算法解决场地分配问题，支持温度衰减、迭代次数、冷却系数等参数自定义，在合理时间内收敛到最优解。

3. **并发安全控制**：采用数据库事务锁机制，确保高并发场景下场地预约的一致性，避免超卖。

4. **超时自动释放**：设置15分钟签到超时机制，未按时签到的预约自动取消并释放场地资源。

5. **响应式布局**：采用 Bootstrap 栅格系统，适配 PC 端和移动端浏览器。
