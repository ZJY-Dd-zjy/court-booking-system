# 🏸 体育馆智能预约系统

> 面向智慧校园的多目标资源智能调度平台 —— 以高校体育场馆预约为切入点
>
> 大学生创新创业训练计划（大创）项目 | 目标：11月通过立项答辩

---

## 📋 项目简介

高校体育馆场地资源紧张，传统人工预约存在信息不对称、排队冲突、资源浪费、分配不均等问题。本项目开发一套**智能化场馆预约系统**，通过在线预约、智能推荐、全局优化分配等功能，提升场地利用率，改善用户预约体验。

**核心创新点**：神经网络满意度预测 + 模拟退火全局优化 的两阶段框架。

## 🚀 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 初始化数据库（如需要）
python create_demo_db.py

# 3. 启动服务
python app.py
# 或双击 run.bat

# 4. 访问系统
# 用户端: http://localhost:5000/login.html
# 管理员: http://localhost:5000/admin.html
```

## ✨ 功能清单

### 用户端
- [x] 用户注册 / 登录（支持普通用户 / 管理员双角色）
- [x] 场地实时状态看板（空闲 / 预约中 / 占用 / 已超时）

- [x] 匹配率统计与对比
- [x] 用户列表与偏好分析
- [x] 超时自动释放（15分钟未签到自动释放）
